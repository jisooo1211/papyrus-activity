파피루스 Drive 연동
마지막 1단계

학생용·교사용 사이트와 Drive/Sheet 구조는 준비되어 있습니다. Google이 요구하는 웹앱 배포 승인만 선생님 계정에서 한 번 해주세요.

1. 백엔드 코드 복사

아래 버튼을 누르면 현재 사이트에 준비된 Code.gs 전체가 복사됩니다.

2. Apps Script에 붙여넣기

1
Google Apps Script에서 새 프로젝트를 만듭니다.
2
기본으로 있는 Code.gs 내용을 모두 지우고, 방금 복사한 코드를 붙여넣은 뒤 저장합니다.
3
배포 → 새 배포 → 웹 앱을 선택합니다.
4
실행 사용자: 나, 액세스 권한: 모든 사용자(Anyone)로 설정해 배포합니다.
5
Drive/Sheets 권한 승인 화면이 나오면 승인합니다.

3. 생성된 웹 앱 URL을 ChatGPT에 보내기

배포가 끝나면 https://script.google.com/macros/s/.../exec 형태의 주소가 나옵니다.

그 주소 전체를 이 채팅에 그대로 붙여 보내주세요.

그러면 내가 config.js에 연결하고 GitHub Pages 배포까지 확인해서 끝낼게. 학생에게는 기존 학생용 링크만 보내면 됩니다.

완성 후 동작

학생이 책방 인증 → 사진이 선생님 Drive의 팀 코드 폴더에 저장 → 제출현황 시트 같은 행에 1·2·3차가 채워짐 → 교사용 관리자 화면에서 전체 모둠과 사진을 확인.
